# 跨层融合对语音连接器有没有用？Qwen3-32B 和 Qwen2.5-72B 上的 A / B 对比

*Adventists.ai 研究笔记，2026-09-28。[English](2026-09-connector-a-vs-b.md)*

**结论：没有稳定的收益。** 我们在 5 组严格对照里比较了两种连接器：B 只读 ASR 编码器最后一层，A 用交叉注意力融合编码器
的三层。在 Qwen3-32B 上，公开口语评测 VoiceBench 的三组对比都是 B 明显更好；在 Qwen2.5-72B 上，A 领先 1–3 分，但在
误差范围内。B 结构更简单、参数更少，而且是主流推理框架能直接支持的结构，所以新的 DuplexJev 模型只做 B。

## 两种连接器

两者都把冻结的 [Qwen3-ASR-0.6B](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) 编码器（18 层，每秒 12.5 帧）接到冻结
的大模型上，只训练连接器。

```
            ┌─ B：第 18 层（最后一层）─────────────────────────────────────────┐
编码器 ─────┤                                                                  ├─► 每 2 帧拼接 → SwiGLU MLP → 大模型
            └─ A：第 18 层 + 交叉注意力（Q = 第 18 层，K = 第 14 层，V = 第 9 层）┘   （每秒 6.25 个音频 token）
                  零初始化，残差相加（多 3.2M 参数）
```

A 的出发点：ASR 编码器的最后一层偏向"说了什么"，中间层还保留更多"怎么说的"（音色、韵律），让连接器回看中间层，
应该有助于性别、情绪这类判断。融合块零初始化，所以 A 在训练开始时和 B 完全一样。

每组对照内部，数据、训练日程、评测代码都相同；每个配置只训一次。

| | | B | **90** | 79 | 76.6 | 54 | 27 |
| | + 性别 | A | 86 | 79 | 72.8 | 89.4 | 27.1 |
| | | B | 87 | 81 | 75.2 | 87.9 | 27.4 |
| | + 情绪 | A | 84 | 71 | 68.4 | 48.8 | 71.8 |
| | | B | 89 | 69 | 72.2 | 51.8 | **85.5** |
| Qwen2.5-72B | 内容（R2） | A | 90 | 74 | 73.1 | 55.9 | 27.1 |

性别、情绪在专门训练之前都是瞎猜水平（50% 和 25%）。误差大约：qa100、ZJU-ML 各 100 题，±4 分；Easy-Turn、性别、
情绪各 800 题，±1.5 分。明显超出误差的只有 Qwen3-32B 只训情绪这一组：B 高 13.7 分。

## 我们的理解

1. **融合不是白捡的收益。** 在 Qwen3-32B 上，它让口语问答低了 6–11 分、情绪低了 14 分；在 Qwen2.5-72B 上略好，但从未
   超出误差。
2. **副语言信息在最后一层里已经有了。** 两种连接器经过决策训练后，性别、情绪都能到 90% 左右；对 Qwen3-ASR 编码器输出做
   线性探针，性别 99%、情绪 91%。
3. **真正的损失在别处。** 直接把转写文字给大模型，Qwen3-32B 的 MMSU 是 76.5，Qwen2.5-72B 是 79.5；换成听语音，两种
   连接器都只剩 56–60。无论哪种连接器，从音频到大模型之间都丢了约 20 分。连接器研究更该在这里下功夫，而不是跨层融合。
4. **部署要简单。** B 就是标准的 Ultravox 结构，装一个小插件就能在 vLLM 上跑
   （[`duplexjev-vllm`](https://pypi.org/project/duplexjev-vllm/)）；A 在每个推理框架里都要改编码器代码。

## 局限

每个配置只训了一次；只试了一种融合设计（第 18/14/9 层、一个交叉注意力块）；只用了一个编码器（Qwen3-ASR-0.6B）；大模型
始终冻结。换一种融合设计、放开大模型训练或者训练得更久，结论都可能变化。32B 和 72B 两批相隔几天、用同一套代码训练；
不同大模型之间的绝对分数不可比，只比较同一组内部。
