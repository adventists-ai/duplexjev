# 让语音判断大模型听懂重音：数据、双门校验、负样本和“来源捷径”

*Adventists.ai 研究笔记，2026-10-08。[English](2026-10-stress-understanding.md)*

同一句话，重读的位置不同，意思就不同（“**我**没说他偷了钱”和“我没说他偷了**钱**”）。中文更明显，停顿位置不同也会改变意思
（“咬死了猎人的狗”）。DuplexJev 让听得见音频的 LLM 用一个 token 给出闭集判断，我们想知道它能不能学会用重音和停顿。

**结论：**

- 原版 DuplexJev 对重音完全无感，中英文都和瞎猜一样，但停顿有一部分用上了。
- 用公开数据做 LoRA 训练后，32B 在训练中**没见过的句子**上，中英文都能找出被重读的词；完整配方下中文重音 94%、停顿 91%。
- 只给正样本会让模型在中性语音上也“听出”重音。加了负样本之后，又发现了一个更隐蔽的问题：模型按**语音来源**（真人 / 某个 TTS）
  而不是按重音来判断。负样本必须在每个来源里都和正样本配对出现。
- 让模型按重音“选意思”的题（文字相同，只能靠语气选）会让口语选择题（VoiceBench）掉 2–4 分；只问“哪个词被重读”就不会掉，
  而且能部分迁移到“选意思”。发布版用的是后一种配方。

| | DuplexJev-32B-Turn | **DuplexJev-32B-Stress** |
|---|---:|---:|
| qa100 / ZJU 主语言 | 96 / 87 | 96 / 87 |
| 性别 / 情绪 | 91.5 / 91.1 | 92.1 / 91.4 |
| Easy-Turn / CoDeTT 中 / CoDeTT 英 / TurnBench-dev | 95.2 / 69.2 / 70.0 / 88.7 | 94.4 / 69.7 / 70.5 / 88.3 |
| VoiceBench OBQA / MMSU | 85.5 / 72.1 | 86.2 / 71.4 |
| 哪个词被重读：中文 DEBATE / 英文 StressPresso（带“无”选项） | 35 / 1 | **92 / 88** |
| 中性语音答“没有强调”：中文 AISHELL / 英文 LibriSpeech | 92 / 50 | **99 / 99** |
| 靠重音选意思：DEBATE 重音（留出句）/ StressTest | 35 / 52 | 83 / 67 |
| 靠停顿选意思：DEBATE 停顿（留出句） | 71 | 75 |

## 1. 起点：重音没用上，停顿用上了一部分

评测都是单 token 选择题，选项循环移位后取平均概率。对照组用不带重音标记的转写代替音频，这一组应当等于瞎猜。

| 零样本 | DEBATE 重音（瞎猜 33.5） | DEBATE 停顿（瞎猜 49.4） | StressTest（50） | StressPresso（50） |
|---|---:|---:|---:|---:|
| DuplexJev-4B-Turn，听音频 | 35.5 | **67.3** | 48.6 | 50.5 |
| DuplexJev-4B-Turn，只读文字 | 33.5 | 49.4 | 50.9 | 50.5 |
| DuplexJev-32B-Turn，听音频 | 34.7 | 70.6* | 52.3 | 53.5 |

\* 32B 的停顿分是在留出句子上测的。

参考：GPT-4o-audio 的 StressTest 是 68.8。DEBATE 论文里三个模型的重音题都在 58–68%。

## 2. 数据和基准

| 数据 | 语言 | 录音 | 用途 | 许可 |
|---|---|---|---|---|
| DEBATE Task_Stres / Task_Pause | 中 | 真人 10 人；120 组重音、198 组停顿 | 按**句子**切分：2/3 训练、1/3 留出测试 | CC BY-NC 4.0 |
| MSPB | 中 | 真人 1 人，160 题 | 测试 | CC BY 4.0 |
| StressTest、StressPresso | 英 | 真人 | 测试 | — |
| Stress-17K（只取 WhiStress 校验一致的部分）、TinyStress-15K（取 4,000） | 英 | 合成 | 训练 | CC BY-NC 4.0 |
| Expresso emphasis 风格（去掉 StressPresso 片段） | 英 | 真人 | 训练 | CC BY-NC 4.0 |
| AISHELL-1、LibriSpeech | 中 / 英 | 真人中性朗读 | 负样本 | Apache 2.0 / CC BY 4.0 |

**切分很重要。** 第一版把 DEBATE 的说话人和句子都放进训练，32B 测出来重音 89.3%。改成按句子切分之后，留出句子上是 88.5%；
同一版的停顿却从 70.6 掉到 54.8，见第 4 节。之后所有中文数字都是在训练中没出现过的句子上测的。

## 3. 合成中文数据：必须过两道门

公开的中文重音数据太少，我们先用 Qwen3-32B 生成 5,000 组“同句不同重读 → 不同意思”的句子，再用 CosyVoice2 合成：
`<strong>` 标记重音，逗号标记停顿；一个说话人读同一句的所有变体。未经二次验证的合成题会把错误答案带进训练，所以加了两道门：

- **文本门**：另一个 LLM（Qwen2.5-72B）看带重音标记的文本，在所有意思里选出正确的一个，所有选项顺序下概率都要 ≥ 0.6。
  这一门检查的是“这个重读位置真的对应这个意思”。
- **声学门**：用 MFA 做字级对齐。同一说话人的各个变体之间，被重读的字在时长、能量、F0 三项里至少两项更突出（时长 > 1.08 倍、
  能量 +1 dB、F0 +0.8 半音），且没有任何一项明显相反。停顿则要求目标位置的静音 ≥ 0.10 s，并且是全句最长。

| | 文本门通过 | 声学门通过 | 两门都过 |
|---|---:|---:|---:|
| 重音 | 39% | 31% | 1,586 条音频 |
| 停顿 | 5.4% | 28.7% | 111 条 → 放弃 |

LLM 写停顿歧义句很差，换模型、开思考、加自检也只有 2.6%。TTS 只有约 1/3 的情况真的把重音读出来了。两门都过的合成数据加进训练后，
增益很小（DEBATE 重音 93.9 → 94.7，停顿 90.2 → 89.7），所以后面的版本只用它来平衡语音来源（见第 5 节），不靠它提分。

## 4. 配比：英文为主 + 中文真人训练句

32B，LoRA r16，4,000 步，混在原有的内容蒸馏 / 副语言 / 话轮数据里一起训：

| 版本 | DEBATE 重音（留出） | DEBATE 停顿（留出） | StressTest | StressPresso | qa100 | VB obqa |
|---|---:|---:|---:|---:|---:|---:|
| 零样本 | 34.6 | 70.6 | 52.3 | 53.5 | 96 | 85.5 |
| v1：DEBATE 全量 + 未校验合成 | 88.5 | **54.8** | 88.5 | 94.1 | 94 | 83.3 |
| v3 h1：英文为主 + DEBATE 训练句 | 93.9 | 90.2 | 88.1 | 92.1 | 95 | 83.5 |
| v3 h2：h1 + 两门都过的合成 | 94.7 | 89.7 | 87.2 | 90.1 | 93 | 81.8 |

v1 只训了重音题，停顿反而从 70.6 掉到 54.8：模型学会了“这句里有个重读词”，原来会用的停顿线索被冲掉了。
v3 加入 DEBATE 停顿题后停顿恢复到 90。

## 5. 负样本和“来源捷径”

所有题都加了“没有特别强调哪个词”这一选项，测两件事：中性语音上能不能答“无”，有重音时能不能选对重读的词。
训练里这一选项和问法都换了措辞，不和评测重复。

**只训正样本会幻听重音。** v3 h1 在中性语音上只有 33%（中文 AISHELL）/ 45%（英文 LibriSpeech）答“无”；零样本反而是 92% / 50%。

**v4：负样本占 1/3，按语言配平。** 中性语音几乎全对（99.7 / 99.5），但英文真人重音题带上“无”选项后只剩 **9.6%**。
原因是负样本全是真人朗读，而带“无”选项的正样本几乎都是合成语音；模型学到的是“真人英文 → 无”。
中文同样有这个问题，用新加的成对检查发现：同一句、同一 CosyVoice 音色读的重读版和中性版，重读版只答对 **1.1%**——
“CosyVoice 的声音 → 无”。

**v5：在每个语音来源里配平。**

- 英文真人：Expresso 重音正样本全部带“无”选项并上采样 4 倍，真人负样本封顶在同样数量。
- 英文合成：用 CosyVoice 以 LibriSpeech 说话人的音色读 Stress-17K / TinyStress 的同一批句子，作为合成负样本。
- 中文：加入两门都过的 CosyVoice 重音正样本，和 CosyVoice 中性读法配对。

| 有“无”选项时 | v3 h1 | v4（1/3 负样本） | v5 p33 | v5 p20 |
|---|---:|---:|---:|---:|
| 中性 → 无：中文 AISHELL | 33.3 | 99.7 | 98.7 | 99.0 |
| 中性 → 无：英文 LibriSpeech | 44.5 | 99.5 | 99.5 | 98.5 |
| 有重音 → 选对：中文 DEBATE | 94.8 | 96.0 | 96.5 | 95.7 |
| 有重音 → 选对：英文 StressPresso | 96.8 | **9.6** | 95.2 | 93.6 |
| 成对检查（同句同音色）：中文 中性 / 重读 | 65.7 / 29.7 | 100 / **1.1** | 98.6 / 51.6 | 97.1 / 57.1 |
| 合成英文：中性 / 重读 | 28.2 / 97.1 | 43.6 / 100 | 99.2 / 99.0 | 99.2 / 99.0 |

经验：**“分布一致”要落实到每个来源，不能只在总体上配平。** 只看总体指标会被骗：v4 的中性语音和中文重音都接近满分，
要靠同句同音色的成对检查和按来源拆开的指标才能发现问题。

**门槛可调。** 从 log p(无) 里减去一个偏置 b，可以在漏报和误报之间移动。p20 在中文成对检查上，b = 2.5 时中性 92.9、重读 68.1；
中文真人数据在 b 取 0–4 时两项都在 95 以上。部署时可以把 b 当成一个旋钮。

## 6. 代价和配方

**重音数据会伤主语言选择题，问题出在“选意思”题。** 带重音能力的模型，VoiceBench（口语选择题）都比线上版低 2–4 分。我们逐个排除原因：

| 32B | 重音数据 | VB OBQA / MMSU | DEBATE 重音选意思 |
|---|---|---:|---:|
| 线上 32B-Turn | — | 85.5 / 72.1 | 34.6 |
| 对照：同样续训，几乎不放重音数据 | — | **86.8 / 72.8** | 34.1 |
| 全部题型，权重 3600 | v5 | 81.5 / 67.8 | 94.3 |
| 全部题型，权重 1500 / 800 | v5 | 83.1 / 70.5 · 84.6 / 70.3 | 93.6 · 92.0 |
| 全部题型 + 内容蒸馏 ×1.6 | v5 | 78.5 / 67.4 | 94.3 |
| “选意思”题只留 1/4 | v5e | 83.5 / 69.9 | 91.1 |
| **只留判断题（哪个词重读 / 在哪停顿 / 有没有强调）** | v5d | **86.2 / 71.4** | 83.3 |

- 续训本身不掉分（对照组），加大内容蒸馏也补不回来。
- 掉分来自“选意思”题：几个选项文字相同，只能听语气选。模型学到的是“做选择题时别看内容”，这个习惯迁移到了 VoiceBench 这类口语选择题上。
- 去掉这类题，VB 回到线上版水平；而只学“哪个词被重读”，也能部分迁移到“选意思”（35 → 83）。

发布版 DuplexJev-32B-Stress 用的就是“只留判断题、权重 1200”的配方。它在主语言、副语言和话轮评测上都和 32B-Turn 持平，差距都在统计误差内（MMSU −0.7、Easy-Turn −0.8、TurnBench −0.4）。
“选意思”要做到 90 以上，目前只能拿 VoiceBench 去换（全部题型的版本是 94 / 81.5），所以这个配方没有发布。

## 7. 局限

- 中文重音数据只有 DEBATE（10 个朗读者），全是朗读语音，不是自然对话。自然对话里重音更弱、更多样，误报率可能不同。
- CosyVoice 合成的重音本身偏弱：成对检查里重读版只答对 52–57%（91 条）；没加负样本的模型也只有 29.7。
- Expresso 中“强调风格但没标注重音”的句子标签存疑，有 67–71% 被判为“无”，这一组不作为中性测试的主指标。
- 评测都是闭集选择题，测的是“能不能用重音”，不等于开放对话里会主动利用重音。
- 我们自己的一个错误：最初构建英文“有重音 + 无选项”测试集时把重音标注解析错了，正确答案成了乱码。修正后所有模型重测，
  文中只报修正后的数字；v4 的结论不变（9.6）。

## 8. 许可

DEBATE、Stress-17K、TinyStress-15K、Expresso 都是 CC BY-NC 4.0，所以带重音能力的权重按 CC BY-NC 4.0 发布，不可商用。
DuplexJev 本身因为情绪数据也是 CC BY-NC。要做可商用版本，需要替换这四个数据集和情绪数据。
