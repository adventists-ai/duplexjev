# 让语音决策模型继续“会聊天”

*2026-10-10 · DuplexJev-4B-Para v1.1 · [English](2026-10-chat-replay.md)*

DuplexJev 用 LLM 的**单 token** 输出读取语音判断。每加一种能力（话轮、重音、非语言声音、说话人），都是在选择题上训练一层 rank-16 LoRA，目标只有一个字母。基于我们模型做语音助手的团队反馈：叠了这些 LoRA 之后，模型“答完就结束”，不好用来正常对话。这篇记录我们查到了什么、怎么修的。

## 1. 实际情况

所有模型用同一批提示、贪心生成：qa100 语音提问、文字聊天、“用同样语气复述”，以及 12 条留出的多轮对话（最后一轮是语音）。

| 模型 | 语音提问（平均 token） | 语音提问 + “请解释” | 文字聊天 | 多轮（上限 300） |
|---|---:|---:|---:|---:|
| 32B 原版（无 LoRA） | 89 | 94 | 160（到上限） | — |
| 32B-Turn → Stress → Para | 81 → 75 → 53 | 80 → 77 → 76 | 160 | — |
| 4B 原版 / 4B-Turn / 4B-Para | 86 / 72 / 53 | 71 / 70 / 61 | 160 | 289 / — / 287 |
| 4B-Para 把 LLM 换回原始权重 | 78 | 69 | 160 | — |

没有一个模型只答一两个字就停，多轮对话长度也没变。但每叠一层 LoRA，**单轮语音提问的回答就更短、更先下结论**（“小刚最矮。”），Para 约短 40%。把 LLM 换回原始权重，长度就恢复了，说明偏移在 LoRA 里，不在连接器。

原因：LoRA 阶段唯一的非判断数据是 Ultravox 的续写任务，提示写的是 “Continue the following text using less than 50 words”，目标只有一句话。判断题目标是一个字母，`max_response_tokens` 默认又是 50。LoRA 从没见过长回答。

## 2. 对话回放，以及途中的两个 bug

我们在 LoRA 数据里加了**对话回放**：对话数据里的用户语音轮次（前面最多 6 轮作为文字历史）、SmoothConv 对话片段和 AISHELL-1 句子，每条配上**原始 LLM 自己对转写的回复**（Qwen3-4B，不限长度；把输入说成“不清楚 / 不完整”的回复已删掉，片段数据里占 38%）。

第一版失败得很厉害：qa100 从 79 掉到 51，8 条语音提问里有 6 条回答“您似乎没有输入任何内容”。原因是我们用的混合损失把所有“答案不是单个字母”的行都送去和**纯文字老师做 KL**，老师的输入是“用转写替换音频”。回放数据的转写是空的，老师看到的就是一条空消息，学生学到的正是老师对空消息的回答。

修复（已开源：[`training/ultravox_patches/chat_replay.diff`](../training/ultravox_patches/chat_replay.diff)）：

1. 转写为空的行，对整段回复用普通交叉熵；
2. 纯文字行（对话里没有 `<|audio|>`）带一个“插入 0 个 token”的占位音频块，让 accelerate 切分 batch 时题和音频保持对齐（否则训练会因索引越界崩溃）；
3. `max_response_tokens` 从 50 放宽到 256；
4. **按行平均损失**（`ML_ASR_CE_ROWNORM=1`）。

第 4 条对判断能力最关键：

| 4B run | qa100 | ZJU-ML | 情绪 | VB OBQA | DEBATE 重音 | POSN 英 | PAIR-pos | StressPresso |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 4B-Para v1.0（无回放） | 79 | 50 | 91.5 | 57.8 | 89.0 | 94.1 | 34.1 | 84.7 |
| 回放，按 token 平均 | 78 | 61 | 88.9 | 48.8 | 77.4 | 75.4 | 14.3 | 71.8 |
| 回放，**按行平均** | 78 | 58 | 91.6 | 55.4 | 89.0 | 90.4 | 34.1 | 82.7 |
| + 4.5 k 条自有对话数据（**发布为 4B-Para v1.1**） | 77 | 58 | 90.0 | 55.2 | 89.9 | 92.0 | 28.6 | 84.2 |

按 token 平均时，一条 256 token 的回复梯度是一个字母判断题的 256 倍，重音掉了 12–20 分；先在每行内平均，每个样本权重相同，几乎全部恢复。

## 3. 还没解决的

- 单轮语音提问仍只答 40–50 token（原版约 86）。回放目标是对陈述和对话轮次的回复；类似考题的语音提问更像判断题。下一步加“语音开放问题”的回放数据。
- v1.1 有少量代价：情绪 −1.5、VoiceBench OBQA −2.6、叹气 AUC 0.81 → 0.71、自然对话里的喘息 0.84 → 0.74。
- 问“你会什么”时，偶尔会扯到通用助手技能。
- 32B 版（同样配方，回复由 Qwen3-VL-32B 语言模型生成）正在训练。
